php基础知识理解

前言

PHP 是运行在服务器上的语言。你写的echo “abc”;并不是显示在编辑器里，而是把abc写进最终发给浏览器的 HTML 里。所以浏览器打开页面后看到abc，用命令行运行php test.php时也会看到abc。这三个东西本质上都是**“把内容送出去”或“把内容看清楚”**的工具，只是用途不一样。

注释

用法与c语言一样，不过这里//也可以用#，他们两个作用一样

echo

输出内容，它就是把字符串原样输出出去的

几个关键点：

echo不是函数，是语言结构，所以括号可有可无，echo(“x”) 和 echo “x” 效果一样，括号只是把内容括起来而已
但多个参数时不能加括号：echo(“a”,”b”) 会报语法错误，只能写 echo “a”,”b”;

因为echo 没有返回值（返回 void）。所以你不能写 $x = echo “hi”;，这是语法错误

print

它也输出字符串，但和echo的区别在于print是一个表达式，它输出完之后，自己会变成数字1

也就是print balabala这一块的值变成1
日常写代码基本上用echo就行

var_dump()

echo/print只会把内容显示出来，但你看不出它的类型

看起来一样，但一个是字符串，一个是整数，写程序时差别巨大。var_dump() 就是用来看值的类型、长度之类的，它是给人自己调试用的，不是给用户看的

string(5) 表示“字符串，5 个字符”；array(3) 表示“数组，有 3 个元素”。

string php与c对比

在C语言里，字符串是字符数组，最后有个隐藏的 \0 作为结束符。长度不固定，找结尾很麻烦。
在PHP里，string 是一种独立的数据类型（字符串），全自动服务，帮你封装好了，不仅存了你的文字，还直接记下了它的长度

php变量

$是什么

在PHP里，$符号就是变量的标志。是一个身份牌，写了这个就让系统把它当成变量处理

在 C 语言里需要先声明类型（如 int a = 1;）。
但在 PHP 里，不需要声明类型，但变量前面必须加 $。
PHP 的变量命名规则（去掉 $ 之后的部分），基本和 C 语言给变量(标识符)命名的规则是一样的
开头必须是字母或下划线，不能是数字
比如 $name、$_age 是对的；$1name 是错的
区分大小写，$a 和 $A 是两个完全不同的盒子
不能用系统保留字，比如不能把变量起名叫 $if、$for、$echo，因为这些词系统自己要拿来当语法用。

预定义变量

他们像c语言里的全局变量，已经被赋值好了，在写的时候可以直接访问使用
1.$_GET：获取通过get方式得到的数据
2.$_POST：获取通过post方式得到的数据
3.$_REQUEST：获取通过get方式和post方式得到的数据
4.$_GLOBALS：php中所有的全局变量。
5.$_SERVER：服务器信息
6.$_SESSION：session会话数据
7.$_COOKIE：cookie会话数据
8.$_ENV：环境信息
9.$_FILES：用户上传文件信息

可变变量

就是套娃嘛

系统是从右往左看的，它先找到$a，发现里面是’b’。然后系统把外面的那个$和’b’组合起来，变成了$b,然后去输出$b的值,结果就是2

变量传值

就和c语言一样的，比较简单

值传递

$b = $a;
相当于$a赋值给$b

引用传递

$b = &$a;
这时候写 $a = 5;，会发现 echo $b; 也会变成 5，它俩现在是一根绳上的蚂蚱，值一样了

作用域

变量局部和全局作用域
还是和c语言很像
在所有函数外部定义的变量，拥有全局作用域。
除了函数外，全局变量可以被脚本中的任何部分访问，要在一个函数中访问一个全局变量，需要使用 global 关键字
在 PHP 函数内部声明的变量是局部变量，仅能在函数内部访问

这样会报错，因为$x是全局变量，函数里看不到

使用gobal关键字
这是从外面拿进来

或者使用$GLOBALS 数组
这是去外面拿

常量

和变量的区别

没有 $ 符号
不能重新赋值
全局生效 常量没有作用域的概念。无论你在函数里面还是外面定义的常量，在代码的任何地方（比如函数内部）都能直接拿来用，不需要像变量那样敲 global。

定义常量

用define() 函数
语法：
define(string constant_name, mixed value, case_sensitive = true)
